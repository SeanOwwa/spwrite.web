Four simple steps

Built on Debian (ARM64), and runs on most modern GTK-based desktops. Follow along in order — it's quick.

1

Download the app

Click the Download Spwrite for Linux button above. Your browser saves a file called Spwrite-Linux-v1.3.5.zip into your Downloads folder.

2

Extract it

Right-click Spwrite-Linux-v1.3.5.zip and choose Extract Here (or run unzip Spwrite-Linux-v1.3.5.zip in a terminal). You'll get a linux_app folder with the spwrite program inside, alongside its data and lib folders. Keep those together — the app needs them to run.

3

Make it runnable

The first time, mark the program as executable. In a terminal, from inside the linux_app folder, run chmod +x spwrite. (Or in your file manager: right-click spwrite → Properties → Permissions → tick Allow executing file as program.)

4

Run it and start writing

Double-click spwrite, or run ./spwrite from the terminal in that folder. That's the whole "installation" — Spwrite is a self-contained app. To get a clickable shortcut in your apps menu, follow the quick steps just below.

Make a shortcut in your apps menu

So Spwrite shows up alongside your other apps and launches with one click:

  1. Move the linux_app folder somewhere permanent, for example ~/Applications/spwrite.
  2. Create a shortcut file by running this in a terminal (it points the menu at the app in that folder):
    mkdir -p ~/.local/share/applications && cat > ~/.local/share/applications/spwrite.desktop <<'EOF'
    [Desktop Entry]
    Type=Application
    Name=Spwrite
    Comment=Calm, distraction-free writing
    Exec=/home/USERNAME/Applications/spwrite/spwrite
    Icon=/home/USERNAME/Applications/spwrite/data/flutter_assets/assets/images/spwrite_logo.png
    Terminal=false
    Categories=Office;WordProcessor;
    EOF
  3. Replace USERNAME with your username (or edit the two paths to wherever you put the folder), then save.
  4. Spwrite now appears in your applications menu. You can also right-click it there and add it to favorites or the dock.

If your desktop warns that the file is from an unknown source, that's expected for an app installed this way — it's safe, it just isn't signed through a store. Allowing it to run once is enough.

Common questions

Which Linux does this run on?

It's built on Debian (ARM64), but it's a standard Flutter desktop app, not a .deb — so it also runs on most other modern ARM64 desktops like Ubuntu and Fedora, as long as GTK 3 is installed. If it won't start, that's almost always a missing GTK 3 (install it with your distro's package manager, e.g. sudo dnf install gtk3 on Fedora or sudo apt install libgtk-3-0 on Debian/Ubuntu) or a very old system library. It targets ARM64 machines, not Intel/AMD x86.

Where is my writing saved?

Right on your machine. Nothing goes to the cloud, and Spwrite works with no internet connection.

How do I remove it?

Delete the linux_app folder (and the spwrite.desktop file if you made one). That's it.

Is it free?

Yes, completely free to use. If it helps your writing, a coffee is always appreciated.

Is this the final version?

Not yet — Spwrite is in beta. It's ready for everyday writing, and a new build ships about every two weeks. To update, download the latest here and replace your old linux_app folder.
