A small update: Spwrite is now desktop-only, the Windows download is x64, and Esc leaves focus mode again.
### Changed
- **Spwrite is now a desktop app.** The web (browser) version is no longer offered. Download Spwrite for macOS, Windows or Linux instead.
- **The Windows download is now x64**, for Windows 10 and 11. There's no separate ARM64 build any more: Windows 11 on ARM PCs run the x64 version through Windows' built-in emulation.
### Fixed
- **Esc now leaves focus mode while you're typing.** Before, pressing Esc only worked when your cursor wasn't in the page — the editor's own Esc action took priority. Now Esc leaves focus mode wherever your cursor is.
